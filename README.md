# zine-stand-firm-
STAND FIRM. merupakan zine independen yang lahir dari kecintaan dan keresahan terhadap PSS Sleman. Melalui kritik, refleksi, dan penghormatan, zine ini menyuarakan tuntutan akan tanggung jawab, transparansi, serta komitmen nyata demi menjaga identitas dan masa depan klub.  THE CLUB. THE PEOPLE. THE IDENTITY.
